# 📜 중학교 3학년 사회(역사) '조선 시대 문화' 퀴즈 웹앱

> **교실 대형 TV 스크린**과 **학생 스마트폰** 어디에서든 편안하게 풀 수 있는 고대비 반응형 웹 기반 퀴즈 프로그램입니다.

---

## 🌟 주요 특징

1. **중학교 3학년 사회(역사) 핵심 10문항 수록**
   - 세종대 과학 기술(자격루, 측우기)부터 훈민정음, 조선왕조실록, 백자, 실학(거중기·수원 화성), 서민 문화(판소리·탈춤·한글소설), 풍속화(김홍도), 진경산수화(정선), 동의보감(허준)까지 핵심 성취기준 반영.

2. **교실 TV & 스마트폰 맞춤형 가독성 극대화**
   - 시인성 높은 다크 슬레이트 테마와 WCAG AAA급 고대비 색상 적용
   - 교실 맨 뒷자리 TV에서도 또렷하게 보이는 대형 폰트 (`24px ~ 36px`)
   - 스마트폰 화면에서도 손쉬운 터치가 가능한 여유로운 4지선다 버튼 (`min-height: 64px`)

3. **즉각적인 피드백 및 친절한 해설**
   - 보기를 누르는 즉시 정답(녹색) / 오답(빨간색) 시각 피드백 제공
   - 중학생 눈높이에 맞춘 1~2문장의 명쾌하고 쉬운 핵심 해설 노출

4. **생동감 넘치는 효과음 및 폭죽 효과**
   - 별도 오디오 다운로드 없이 브라우저 내장 **Web Audio API**로 재생되는 정답 팡파레 & 오답 사운드
   - 교실 상황에 맞게 켜고 끌 수 있는 상단 음소거(🔊/🔇) 버튼
   - 퀴즈 완료 시 점수에 따른 축하 콘페티(폭죽) 애니메이션

5. **결과 확인 및 다시 풀기**
   - 100점 만점 기준 점수와 맞힌 개수, 격려 메시지 표시
   - '다시 풀기' 버튼으로 언제든 처음부터 재도전 가능
