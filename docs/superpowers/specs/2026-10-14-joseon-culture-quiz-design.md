# 중학교 3학년 사회/역사 '조선 시대 문화' 퀴즈 웹앱 설계서

## 1. 개요 및 목적
- **대상**: 중학교 3학년 학생 및 교사
- **주제**: 조선 시대 문화 (세종대 과학기술, 훈민정음, 백자/분청사기, 조선 후기 서민문화, 실학, 진경산수화 등)
- **주요 목적**: 교실 TV를 통한 단체 퀴즈 풀이 및 학생 개인 스마트폰을 통한 자기주도 학습 모두에 최적화된 반응형 퀴즈 웹앱 제공.

---

## 2. 화면 및 UI/UX 디자인 원칙
### 2.1 가독성 및 반응형 레이아웃
- **폰트**: 고대비 산세리프(Pretendard / 시스템 폰트 폴백), 두꺼운 굵기(Bold)와 높은 명도 대비(WCAG AAA 준수) 적용
- **글자 크기 (Fluid Typography)**:
  - 교실 대형 TV / 프로젝터 (1920x1080 이상): 문제 텍스트 `28px ~ 36px`, 보기 버튼 `22px ~ 26px`
  - 스마트폰 모바일 (360px ~ 480px): 문제 텍스트 `20px ~ 24px`, 보기 버튼 `17px ~ 20px`, 충분한 터치 영역(최소 56px 높이)
- **시각 피드백**:
  - 선택지 클릭 즉시: 정답은 선명한 에메랄드 그린 배경 + 체크 아이콘(✓), 오답은 선명한 루비 레드 배경 + X 표시
  - 정답 여부 배지(정답입니다! 🎉 / 아쉽네요! 💡)와 함께 1~2문장의 명확하고 쉬운 해설 표시
  - 하단에 '다음 문제' 버튼이 직관적으로 활성화되어 충분히 해설을 읽은 뒤 다음으로 이동 가능

### 2.2 효과음 (Web Audio API)
- 외부 오디오 파일 다운로드 없이 브라우저 내장 Web Audio API 오실레이터로 경쾌한 정답 차임벨(Major chord arpeggio)과 오답 효과음 생성
- 우측 상단에 🔊/🔇 음소거 토글 버튼 제공 (교실 환경에 따라 소리 On/Off 가능)

## 3. 퀴즈 문항 데이터 구성 (10문항)
중학교 3학년 사회/역사 교육과정에 맞춘 핵심 10개 주제:
1. **훈민정음 창제**: 세종대왕의 애민 정신과 한글 창제 목적
2. **조선 전기의 과학 기술**: 측우기, 앙부일구, 자격루
3. **조선왕조실록 및 의궤**: 유네스코 세계기록유산과 철저한 기록 문화
4. **조선 도자기의 변천**: 고려 상감청자 → 조선 전기 분청사기/순백자 → 조선 후기 청화백자
5. **실학과 농촌 개혁**: 정약용의 여유당전서, 목민심서, 거중기 활용 (수원 화성)
6. **서민 문화의 발달**: 조선 후기 판소리, 탈춤, 한글 소설(홍길동전 등)
7. **풍속화와 진경산수화**: 김홍도, 신윤복의 서민 생활 풍속화 및 정선의 진경산수화
8. **대동여지도**: 김정호가 제작한 정밀 목판본 전국 지도
9. **의학 발전**: 허준의 『동의보감』 (유네스코 세계기록유산)
10. **유교 윤리 보급**: 『삼강행실도』와 『국조오례의』

각 문항 데이터 모델:
```javascript
{
  id: 1,
  question: "조선 전기 세종 때 백성들이 스스로 시간을 알 수 있도록 만든 자동 물시계는 무엇일까요?",
  options: [
    "앙부일구 (오목 해시계)",
    "자격루 (자동 물시계)",
    "측우기 (강우량 측정기)",
    "혼천의 (천체 관측기구)"
  ],
  answerIndex: 1,
  explanation: "자격루는 물이 차오르면 쇠구슬이 굴러 종과 북을 쳐서 자동으로 시간을 알려주던 시계입니다."
}
```

## 4. 핵심 기능 흐름 (Flow)
1. **시작 / 진행 화면**:
   - 상단 진행률 프로그레스 바 (1/10 ~ 10/10) 및 현재 점수 카운터
   - 중앙 카드: 큼직한 문제 번호 태그와 질문 텍스트
   - 4개 선택지 버튼 (선택 전 hover 효과, 선택 후 즉시 정답/오답 하이라이트)
   - 피드백 카드: 정답/오답 결과 + 알기 쉬운 핵심 해설 + '다음 문제' 버튼
2. **결과 화면 (10번 문항 완료 후)**:
   - 총점 (100점 만점 기준 점수 및 정답 개수: "10문제 중 9문제 정답!")
   - 점수에 따른 칭찬 메시지 (예: 100점 "조선 시대 문화 마스터! 👑")
   - 만점 또는 고득점 시 축하 콘페티(폭죽) 애니메이션 효과
   - '다시 풀기' 버튼 (문제를 다시 처음부터 리셋하여 풀 수 있음)
